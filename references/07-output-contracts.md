# 07 · 输出契约

## 1. 模式与输出栏目

| 模式 | 输出栏目 |
|---|---|
| **M1 生成** | ①【角色打法分析】（简表）→ ②【战术节奏图】→ ③【分镜提示词】→ ④【负面约束】 |
| **M1 精简**（用户说"只要提示词 / skip story"） | 只出 ③ + ④ |
| **M2 补强** | ①【诊断表】→ ②【改写稿】→ ③【负面约束】 |
| **M3 约束** | 只出【负面约束】6-8 条 |
| **M4 讲戏** | ①【角色打法分析】→ ②【接触链】→ ③ 关键建议 3-5 条（不出全文） |

**用户没说"要故事"时，默认不写故事。** 故事模块（600-1500 字短篇，中段穿插 3-6 个高燃名场面）仅在用户明确要求时输出。

---

## 2. ①【角色打法分析】（表格，每角色一行）

| 角色 | 载体 | 有效距离 | 节奏基因 | 接近方式 | 处理来招 | 抢回主动 | 重击形态 | 被击飞后如何刹停回冲 |
|---|---|---|---|---|---|---|---|---|

外加一行：**画风基准**（四要素一句话：色调 + 光质 + 作画质感 + 镜头特征）——这句在分析与提示词中**共用，不换措辞**。

---

## 3. ②【战术节奏图】

用 ASCII 图 + 短表，不写散文：

```
路线：近岸石阶(起点) ──蹬壁跃起──→ 檐顶(中距) ──错身掠过──→ 庭院纵深
      ──被轰穿照壁──→ 后院水畔(终结落点，离起点最远)

回合：R1 1-3.5s | R2 3.5-6s | R3 6-9s | R4 9-13s | 终结 13-15s
重击：较早重击 @6.5s（撞穿照壁，沿飞行线犁开） | 终结重击 @13-15s（水面终结帧）
跳位三连：〔贴脸·右·低位〕→〔全景·左·檐顶〕→〔中景·正面·水畔〕
怼脸弹射：@3.5s / @9s（换侧、换仰角，不复用正面首帧）
```

---

## 4. ③【分镜提示词】格式规范

- 按**时间顺序**写 N 个镜头，**连续覆盖 0.0 → 总时长，不重叠、不留空档**。
- 每个镜头开头：**`[起止秒]` + 景别/机位 + 摄影机怎样看当前动作**，随后直接写人物动作、方向、位置变化、当下结果。
- **先完成动作与切镜，秒数最后填**。
- 长镜头只围绕**一个主要位置变化**展开；短镜头只抓**一个突然发生的攻防变化**。
- 落地 / 刹停 / 翻身 / 扑近**不单独成镜**，作为下一镜第一拍直接接进攻防。
- **终结重击写成一整镜**：高速进入 → 进入慢镜头蓄力 → 接触瞬间恢复高速 → 俯冲跟落 → 落地破坏 → 终结帧，**命中后不切镜**。

### 图片标注（仅多图输入时）

每个角色与场景在正文**第一次出现时**带 `@图N`，紧贴名称**前面**：`@图1白衣剑客`（不是"白衣剑客 @图1"）。编号按用户给图顺序，首次标注后不再重复。

### 正文语言（简单利落 · 像在现场讲戏）

```
✅ 每句提供一个能直接拍出来的新画面：人物动作 / 移动方向 / 空间跨度 /
   镜头变化 / 身体结果 / 场景破坏 / 技能轨迹 / 光影变化 / 前景遮挡
✅ 连续动作用短句串起来：顿号 + 具体动词
✅ "因速度过快带起庞大气浪"这类把画面效果和动作绑在一起的短因果句 —— 可以用
❌ 解释上一句的话 —— 删
❌ 发力原理解释（"腰马合一将力量自地底传导至拳面"）—— 删
❌ 招式名、门派名堆砌 —— 删（除非用户要求标注）
❌ 坐标、数组、表格、JSON、接触编号、内部分析、自检 —— 一律不出现
```

**交付正文必须清除全部自查编号**，只保留 `[时间戳]` 与 `[反馈]`，是一段纯净连续文本。

## 5. 字数契约

| 总时长 | 正文硬下限 | 通常区间 | 镜头数 | 节点下限 |
|---|---|---|---|---|
| 5s | 400 字 | 500-700 | 4-6 | 18 |
| 10s | 900 字 | 1100-1600 | 8-12 | 35 |
| 15s | 1200 字 | 1400-2000 | 10-14 | 50 |

**字数不足 = 特效 / 位移反馈 / 瞬移没写够，去补细节而非注水。**
**字数超出 = 删重复动作、重复效果、没改变画面的句子，不删特效。**

---

## 6. ④【负面约束】写法

**只写 6-8 条**，只负责**画面稳定性**，不复述内部规则：

| ✅ 该写 | ❌ 不该写 |
|---|---|
| 人物外形 / 服装 / 武器一致 | 内部接触数量、重击流程、导演方法 |
| 身体结构稳定（多臂 / 多翼 / 机甲部件数量位置） | 门派动作清单 |
| **双方身体各自独立不融合**（防 morphing） | 规定角色必须重复哪些招式 |
| 场景与已有介质一致 | 限制尚未决定的创意答案 |
| 已有伤势与破坏连续 | 空泛质量词（"高质量""不要模糊"） |
| 画风与渲染质感锁定 | 复述节奏合同 |

**模板（按需取 6-8 条）**：
```
1. 角色外形、服装配色、武器形制全程不变，不新增图片中不存在的装备或肢体
2. 两名角色身体各自独立，不出现肢体交缠、融合、变形或额外长出部件
3. 武器与身体的连接关系稳定，握持手与持械部位始终一致
4. 场景中的[具体介质/结构]保持原有位置与材质，破坏只发生在被攻击的落点
5. [较早重击]造成的破坏在后续镜头中持续存在，不自行复原
6. 面部特征与表情细节清晰可辨，不被特效、遮挡或闪光完全覆盖
7. 画风与渲染质感全程统一：[四要素画风句]
8. 画面持续运动，无静止帧、无画面冻结、无慢放卡帧
```

## 7. 交付前自检（内部执行，不输出）

```
□ 动作层：谁在打、用什么打、打中哪、去哪了 —— 每镜都有答案
□ 每个角色一套打法，十五秒不变风格；刹停回冲也符合同一套
□ 接触全部一触即分，分离写成看得见的动作
□ 每次接触都改变位置/方向/武器路线/主动权，并长出下一动作
□ 回合：3-4（10s）/ 4-5（15s）个，每回合五拍齐全
□ 每个进攻爆发前有独立可读的蓄力慢拍（进攻蓄力型 ≥3）
□ 重击三档不越级；终结从当前破绽打开新路线，不是较早重击的加强版
□ 终结帧：主色抽掉环境、保留人物细节、结果沿攻击方向铺开、之后零追加
□ T1 零裸写冻结词；升格绑流动元素 + ramp in→snap back
□ T2 切点在动作中段、方向 match-cut、收势变起势
□ T3 净位移 A→B→C→D，零"归位/回到原处"
□ R1 三段一体全覆盖：攻击有落点+后果，位移有地面回馈+速度特写，反馈带特效
□ 破坏从落点材质取材；介质取自场景，不默认沙尘
□ 招式现造，无老三样，1-2 招从角色独有部件长出
□ 零泛词；违禁词扫描清零
□ 时间戳连续覆盖、不重叠；终结重击整段在同一镜内
□ 字数达标；正文无编号、无表格、无 JSON、无内部分析
□ 分析与提示词：同一角色、同一武器、同一画风句，无新增元素
```

## 8. 输出末尾标注（一行）

```
实际字数 XXX + 动作层已自洽 + 结构层（回合/重击/终结帧）已排布 +
连续层（T1/T2/T3）已通过 + 反馈闭环已全覆盖 + 违禁词已安全替换 + 画风已锁定
```
