# 06 · 诊断与改写（M2 补强模式）

> 用户拿来一段"打戏提示词 / 分镜 / 已生成的视频描述"，要你补强。
> 先诊断、再改写，**不整段重写**——保住用户已有的有效部分。

## 输出格式（M2 固定）

```
一、【诊断表】  病症 | 证据（引用原句） | 病因 | 处方     ← 表格
二、【改写稿】  完整的分镜提示词正文（可直接复制）
三、【负面约束】6-8 条
```

诊断表按**严重程度分组**（🔴 致命 / 🟡 明显 / 🟢 优化），每条必须**引用原文中的具体句子**作为证据，不写"感觉有点慢"这种空判。

---

## 病症-病因-处方总表

| # | 病症（用户会说） | 病因 | 处方 |
|---|---|---|---|
| 1 | **画面一顿一顿、卡住、像 PPT** | 写了 A 类冻结词（定格 / 停格 / 顿帧 / 慢动作 / 时间静止 / 子弹时间 / hit-stop） | 全量删除，改用不停画面手法：白闪一两帧 + 镜头猛震一颤 + 命中点径向速度模糊 + 色彩瞬间提亮。要"顿一下"→ 用**绑流动元素的命中顿微升格**（ramp in→snap back） |
| 2 | **发飘、接不上、肢体扭曲、糊成一团** | 硬切没交代动作怎么接（切在静止帧、前后方向不一致、只写发力帧不写承接） | 补 T2：切点落在动作中段、方向 match-cut、残影与速度线指向落点、上一招收势长成下一招起势。插入动势衔接词（`03 §2`） |
| 3 | **打回原点 / 结尾绕回开头** | img2video 首帧引力 + 正文有"归位 / 回到原处"或反复用与首帧雷同的正面居中构图 | 删禁字；重排 A→B→C→D 净位移；终结落点放在离原点最远的区域；怼脸弹射换角度（侧 / 仰 / 斜） |
| 4 | **没打击感 / 全程一样快 / 看着累** | 匀速密不透风，缺慢拍-爆发落差（"全程快 = 没有快"） | 给每个回合补**独立可读的蓄力慢拍**（B 类，画面照常动）+ 收势喘息。检查进攻蓄力型 ≥3 次（不是只有防守接招型） |
| 5 | **特效空放 / 朝空气放烟花 / 看着满实际空** | 攻击没有明确落点与匹配分量的后果，只贴笼统 [崩解 + 火花] | 补 R1 三段一体：动作动词 → 具体受体 → 与分量匹配的后果 → 回馈特效。受体按四维现造（`04 §2`） |
| 6 | **两人黏在一起 / 缠斗 / 像摔跤** | 违反一触即分 | 所有接触后立刻拉开到武器/四肢完全展开距离；分离写成后跳 / 侧滑 / 蹬地弹开；删除擒拿、锁技、搂抱、骑压 |
| 7 | **站着放技能 / 原地砸墙 / 单体戏很空** | 单体反站桩失败 | 补三强制：瞬移跳位（贴脸 A→高空 B→远景 C）、技能招式化（有形态/轨迹/因果）、动作多样性（禁止连续 3 个同质砸场景） |
| 8 | **招式千篇一律 / 每条都一样** | 套了固定招模板（三重残影 / 坍缩核心 / 贯穿云层光柱） | 按当前角色造型/武器/材质现造；**至少 1-2 招从角色独有部件长出**（獠牙 / 面甲 / 尾 / 翼 / 兵装挂点 / 披风） |
| 9 | **破坏贬值 / 每击都炸楼 / 终结不够炸** | 破坏越级，三档混用 | 重排三档：普通 ≤ 单体物件；较早重击沿飞行路线犁开；终结全场最大。前一档不抢后一档规模 |
| 10 | **慢都堆在开场，攻击时没慢一下** | 蓄力慢拍溶进连招 run-on 一闪而过 | 把蓄力慢拍**独立成一拍、给它视觉留白**，从连招串里拆出来 |
| 11 | **刀写出了锤的感觉 / 打法不像这个人** | 武器自洽失败、专属打法缺失 | 回到 `01 §1-2` 重问四问（握持与重量 / 有效距离 / 攻击方向 / 出手破绽），重写打法 |
| 12 | **结尾拖沓 / 打完停住再爆闪 / 拉远收尾** | 违反收尾铁则 | 终结重击 + 终结帧 ≤1 秒；爆闪与命中**同步**发生（不是打完→停住→再闪）；删除之后的所有追加（起身、收招、远景、余震） |
| 13 | **密度不够 / 看着慢** | 有效节点不足（或水分太多：同质重复 / 环境反应 / 纯状态凑数） | 用严格数法重数；靠连招拆分、攻防往复、过渡微动作、疯切制造节点加密。⚠️ 加密时**不许删描写**，动作越密特效越满 |
| 14 | **首帧对不上 / 开头跳变** | 开局加了参考图里没有的环境空镜或运镜 | 0-1s 从图中主体当前姿态、当前景别直接启动，第一个动作发生在主体身上；1s 后才疯切 |
| 15 | **要动漫感但出来是写实 CG 在动** | 参考图本身是写实 / 国风 3D 渲染 | 这不是 prompt 能救的：**先把首帧图转成动漫赛璐璐画风**，再拿转出的图当首帧 |
| 16 | **镜头太碎看不清 / 疯乱** | 镜头数超载但 T2 没满足 | 降档（疯切流 → 标准流），或保留密度但补齐每次切点的动势接力 |

## 改写四步

```
1. 定位  ── 通读原稿，逐条对照总表打标，标出证据句
2. 分层  ── 判断病在哪一层：动作层（01）/ 结构层（02）/ 连续层（03）/ 反馈层（04）
          ⚠️ 先修动作层，再修结构层，最后才动呈现层
3. 重写  ── 保留用户已有的有效招式与设定，只替换病变段落，不整段重写
4. 回读  ── 用 05 §7 速查表过一遍；相邻镜头连起来读，看是否还接得上
```

## 常见误诊提醒

| 用户说 | 可能不是 | 真正病因 |
|---|---|---|
| "不够快" | 镜头切得不够碎 | 慢拍不够沉（落差不足），或节点密度不足 |
| "太乱了" | 特效太多 | 缺动势衔接（T2），与特效量无关 |
| "力量感不够" | 破坏不够大 | 命中前缺半拍蓄力慢拍（"砰"不成立） |
| "角色变了" | 一致性约束没写 | 画风描述跨模块换措辞了（R6 漂移） |

---

## 改写稿的分寸

- **保住用户的原创设定**：招式名、世界观、角色关系、已定胜负——不动。
- **只替换病变段落**，并在诊断表里说明"改了哪一句、为什么"。
- 用户只要"改这几处"时，就只改这几处，**不顺手全篇翻新**。
- 改完给**完整可复制的正文**（不要让用户自己拼贴 diff）。
