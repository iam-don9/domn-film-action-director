# 03 · 连续与运镜层

> 这一层决定打斗**够不够燃、接不接得上**。
> 三条铁律：时间不停（T1）/ 动作不断（T2）/ 空间不回（T3）。

---

## 1. ★★★ T1 连续运动、禁停格（优先级最高）

**病因**：番剧里的冲击帧 / hit-stop 只有 1-2 帧、眨眼即过。但 AI 视频模型（即梦 Seedance / Kling）**没有帧级控制力**——你写"定格 / 停格 / 顿帧 / 慢动作 / 升格 / 子弹时间 / 时间静止"，它会把整段画面**真的停住零点几秒**。这些指令一堆，视频就变成"打几下→停→打几下→停"。

| 规则 | 内容 |
|---|---|
| ① | 全片画面**必须持续运动**，绝不出现整帧静止 |
| ② | 冲击强调一律改用**不停画面**的手法：白闪一两帧（画面继续走）、镜头猛震一颤、命中点径向速度模糊、速度线爆开、色彩瞬间提亮 |
| ③ | 升格分两级、**受控放开**：**命中顿微升格**（每个关键爆点 ~0.3-0.5s，可多次）+ **名场面大升格**（巅峰那 1 次，≤0.4s + 360° 环绕） |
| ④ | **禁用词**：定格、停格、顿帧、hit-stop、凝滞、静滞、悬停、子弹时间、时间静止、时停 |
| ⑤ | "快到看不清"靠**速度线 + 残影**表现，不靠停画面 |

**两级升格的唯二铁条**：
1. **必须绑流动元素**——碎屑 / 火花 / 水花 / 气浪仍在缓慢流动外扩，不是冻结
2. **时间轴 ramp in → snap back**，不裸停

> ⚠️ 分清"停格"与"慢拍"：T1 禁的只是 A 类（真放慢时间 / 真停住）；B 类低幅度慢拍（蓄力 / 接招 / 收势）**不在此列，反而是节奏感主来源，必须有**。别把"禁停格"过度执行成"全程不许慢半拍"。

## 2. ★★ T2 动势衔接、动作接力（治"疯切被做成疯乱/发飘/接不上"）

**病因**：番剧疯切之所以丝滑，是人肉原画师让"动势（运动方向 + 速度矢量）**跨切延续**"——上一刀的劲儿，下一刀接着走。但 AI 视频没帧级控制、做不出干净剪辑，你只堆"每 0.2s 硬切到新方位"却不交代动作怎么接，它就把瞬移执行成**肢体扭曲（morphing）、位置乱飘、动作没做完就跳走**——"疯切"变"疯乱"。刀数够、却不丝滑。

| 规则 | 内容 |
|---|---|
| ① **弧线跟随** | 每个动作走完整弧线（起势→发力→跟随 follow-through），别只给发力那一帧就切走，留一点收势让动作"落地"，别处处半截 |
| ② **切在动作中段** | 切点落在挥砍 / 突进**正发力的中途**，用动作本身盖住剪辑。严禁在静止帧、姿势停顿处切 |
| ③ **方向接力 match-cut** | 硬切 / 瞬移前后运动方向一致——上一镜向右上挥出，下一镜就从右上续着走；**残影链与速度线一律指向落点**。省略的是移动过程，不是移动方向 |
| ④ **收势变起势** | 上一招的收尾直接长成下一招的起手，动作像一条不断的线穿过所有切点。残影 / 速度线是承载这条线的胶水，不是遮盖切换的遮羞布 |

**与 T1 的分工**：T1 管"画面别停"，T2 管"动作别断"——两条合起来才是"丝滑高速"。
**疯切密度不用砍**（照样快、照样碎、节点照样达标），要补的只是"每一刀都接得上"。

### 动势衔接词库（写正文时用这些把切点缝起来）

| 用途 | 词 |
|---|---|
| 接力连词 | 顺势、借力、劲道不断、收招不停、一气呵成、衔尾续挥、承着上一击、势头未歇、余力顺转、劲走连贯 |
| 方向延续 | 顺同一弧线续挥、残影链指向落点、速度线顺移动方向铺满、自上一击落点直接续出、动势不折、切点落在挥砍/突进中途 |
| 弧线跟随 | 完整挥出带 follow-through、收势自然坠落、惯性带动身形续转、末端拖尾顺势甩出 |

**反面禁写**：相邻两镜方向/姿态互不相干地硬拼、在静止帧/姿势停顿处切、只写发力帧不写承接。**这三条正是发飘 / morphing 的元凶。**

## 3. ★★ T3 空间单向推进、禁回原点（治 img2video"首帧引力 / loopback"）

**病因**：img2video 对参考图首帧忠诚度极高，会把它当"家"——人物动着动着被拽回起始位置与构图，甚至片尾绕回开头（模型天生想让片子能 loop）。若正文再出现"归位 / 回到坐台 / 落回原处"，或反复用与首帧雷同的正面居中构图，等于亲手把它送回起点。

```
  起点 A ──→ B ──→ C ──→ D（终结落点 = 离 A 最远）
     ✗ 绕圈回到 A        ✓ 累积净位移，越打越远
```

| 规则 | 内容 |
|---|---|
| ① **单向推进** | 位置沿 A→B→C→D 累积净位移、越打越远离起点（起手区 → 中段扫过场景 → 终点落在远端 / 高处 / 另一侧结构前）。跳位三连是"往前跳"不是"绕圈跳" |
| ② **末帧 ≠ 首帧** | 靠"最后一击就发生在离原点最远的新区域"自然达成。**不靠在爆闪后另写"末帧定格在…背身立于…"**（既违反收尾爆闪即止、又把收尾拖散） |
| ③ **禁字** | 正文不写：归位 / 回到原处 / 落回原座 / 回到起点 |
| ④ **换角度** | 怼脸弹射换角度（侧 / 仰 / 斜），不反复复刻正面首帧构图 |

**与首帧锚定的分工**：0-1s 锚住首帧起手（该守），1s 之后必须持续推进离场——**锚开头、不锚全程**。

## 4. 镜头数三档（调和"疯切派"与"连续派"）

| 档 | 镜头数（15s） | 平均镜头 | 适用 | 风险 |
|---|---|---|---|---|
| **紧凑流** | 6-9 | 1.7-2.5s | 写实武侠、机甲、巨兽、强调动作可读性 | 密度不够易显慢 |
| **标准流**（默认） | 10-14 | ~1.2s | 通用，动作与节奏平衡 | — |
| **疯切流** | 18-28 | 0.3-0.6s | 番剧动漫、超能力、能量系 | 极易做成疯乱 → **必须先满足 T2** |

**硬指标**：
- 疯切流：≥18 个不同机位 / 切换，平均镜头 ≤0.5s，0-1s 首帧锚定段可稍长
- 所有档位：**镜头长短必须有明显反差，不平均分配时间**
- **同一个动作可以跨镜完成**：上一镜停在动作还没结束的位置，下一镜从**同一方向和速度**继续，不能重新起手、重新转身或突然换方向

**镜头是动作的结果，不是装动作的格子。** 先完成动作与切镜，最后填秒数。

### 不该单独成镜的

落地、刹停、翻身、扑近这类**回复与赶路动作**不单独成镜，作为**下一镜的第一拍**直接接进攻防。
只负责落地、刹停、赶路的纯过渡镜头 = 删。

## 5. 运镜库

| 段落 | 运镜 |
|---|---|
| **开场（1s 后才用，0-1s 锁首帧）** | 荷兰角疾切 / 贴脸特写硬切全景 / 甩镜入战糊成流光 / 微观特写骤然拉远 / 侧面疾驰跟拍 / 超低机位贴身跟跑 |
| **博弈段** | 荷兰角攻防急切 / 甩镜衔接每一招 / 贴脸↔远景暴力反差跳切 / 残影拖尾横移 / 交错擦身冲出（不停顿） |
| **对垒段** | 360° 高速环绕旋转 / 碎屑径向飞散拖尾 / 名场面大升格特写（≤0.4s，碎屑仍流动）/ 推轨逼近面部再急速拉远 / 蓄力集中线内收 |
| **冲击强调**（每关键命中，画面不停） | 白闪一两帧 / 色彩瞬间提亮 / 命中点径向速度模糊 / 镜头猛震一颤 / 抽象放射背景瞬闪 |
| **重击后** | 超快后拉 / 快速追远 / 转超远景（用后拉速度本身表现力量，不在空画面停留）/ 俯冲急坠跟落 |
| **余波** | 气场收敛中缓慢拉远 / 低角度仰拍 pose 剪影 / 残影消散中的落定 |

**摄影机不必一直跟着人物跑**。它可以固定等待人物瞬间穿过，可以迎着攻击后退，可以跟人物一起翻转，也可以在人物飞出以后猛然后拉到超远景。

**远近变化要大胆**：人物可以从画面中的小点突然变成占满前景的拳头 / 身体 / 武器；命中以后再用远景看清人物飞过多远。近景中的拳头、武器、身体、碎片、场景物可以快速扫过镜头（前景遮挡）——**遮挡结束后，双方位置必须已经改变**。

## 6. 瞬移跳位（引擎一）

番剧里角色"瞬移"不是真的表演位移，而是**用镜头把移动过程省略掉**制造的错觉。

| 手法 | 写法 |
|---|---|
| ① **硬切跳位**（主力） | 招式命中 / 挥空的瞬间硬切 → 下一帧主体已在完全不同的【景别 + 方位 + 高度】。★ 切前运动方向与切后落点方位必须一致、残影与速度线指向落点（T2） |
| ② **残影留位** | 主体在 A 位置留下一道 / 多道残影，实体已出现在 B 位置 |
| ③ **速度线掩护** | 一道横向速度线 / 集中线扫过画面，主体擦着线从一端瞬闪到另一端 |
| ④ **交错错身** | 两人高速擦身而过、错身继续冲出（画面绝不停顿），其中一人身形在冲出中一颤——被命中的反馈在运动里爆发 |
| ⑤ **怼脸弹射** | 轮到谁反击，谁就从极远"唰"地弹到画面最前方，拳头 / 刀尖 / 脸怼到镜头前，超近景冲脸 + 径向速度模糊 + 速度线朝镜头收束 |

★ 硬指标——**跳位三连**：全片至少嵌 2-3 组"位置跳变链"，每组内主体的【景别 / 方位 / 高度】**至少两项**发生跳变。

```
范例：〔贴脸特写·画面右·低位〕→硬切→〔全景·画面左·高空〕→硬切→〔中景·正面·贴地〕
```

- 每 2-3 秒必须发生一次跳位，绝不让主体在同一景别方位停超过 2 秒
- 跳位要累积成净位移、越跳越远离起点（T3）
- **瞬移是"招式之间的连接"，不是主体——跳到新位置就要立刻打出一个不同的招**，别为跳而跳、空跳不打

## 7. 特写标点库（insert cut = 节奏的标点符号，不是装饰）

每个特写 = 一个新镜头，**不涉停格**，对 AI 视频完全安全。

| 特写 | 专职 | 插入位置 |
|---|---|---|
| 握拳 / 攥刀 | 预告发力（"上膛信号"） | 出招前 |
| 脚掌蹬地 / 碾地 | 交代"力从哪来" + 强调重量 | 突进 / 踹击前（配尘土 / 地裂） |
| ★ 移动速度特写 | 卖"快"（区别于蹬地=力源）：腿部 / 脚步 / 身体局部 / 衣摆翻飞大特写 + 满屏速度线 + 地面回馈 | 位移过程中 |
| 刀出鞘 / 举械 / 寒光 | 制造期待 | 交锋前 |
| 眼神 / 瞳孔锁定 | 延迟满足（"下一帧要出大事"） | 命中前一瞬 |
| 命中局部（拳砸 / 刃入） | 节奏重音 · 落点 | 命中瞬间，切对侧角度 |
| 被击者反应 / 踉跄 | 因果闭环之"果" | 命中后一拍，稍长 |

**一个完整重音单元 = 蓄力特写（因）→ 命中（连接）→ 反应特写（果）。** 别只画命中不给反应，否则冲击没有落点。

## 8. 首帧锚定与画风（图生视频头号铁律）

### 首帧锚定
- 给了参考图 = **参考图就是视频第 1 帧**。0-1s 从图中主体的当前姿态、当前景别直接启动，第一个动作发生在主体身上。
- 严禁开头加图里没有的环境空镜或运镜（如"镜头贴地前推掠过霓虹""俯冲镜头砸向战场"）——会让首帧对不上、画面突兀跳变。
- 无参考图：从主角主体的近景 / 特写切入，**主体先入画先动**，不用环境空镜开场。
- 疯切瞬移从 **1s 之后**才全面展开。

### ★ 画风由参考图决定（决定动漫感成败）
图生视频里，视频模型会**死死保持参考图的渲染质感**——参考图是写实 / 国风 3D CG，整条视频就是"写实 CG 在动"，prompt 里写再多 anime sakuga / 赛璐璐 / 描边也救不回来（模型对首帧渲染的忠诚度，**远高于对文字画风词的服从**）。

> **要动漫感，首帧参考图本身就必须是日式赛璐璐 / 手绘动漫渲染。**
> 手上只有写实 / 国风角色图 → 先用出图工具（MJ niji / 即梦动漫模型 / nano）转成动漫赛璐璐画风，再拿转出的动漫图当首帧。
> **prompt 只能控运动 / 运镜 / 特效，控不了"这一帧是不是动漫渲染"——那是参考图说了算。**

### 画风锁定四要素（一句话含：色调 + 光质 + 作画质感 + 镜头特征）

| 风格 | 描述模板 |
|---|---|
| **现代作画流**（默认 · ufotable/MAPPA） | 高饱和能量撞色，流体般粒子海量浮游，电影级构图与体积光，丝滑 sakuga 作画，命中重震镜白闪，青白/品红能量辉光 |
| **少年热血**（龙珠/火影） | 高对比爆气色调，集中线满屏，大气场斗气环绕，光束对轰，瞬身残影频闪，粗线条硬阴影 |
| **剑戟作画**（Fate 味） | 冷冽金属光质，刃光青白残轨，暗调场景点缀火星，居合名场面，优雅弧线运镜 |
| **复古赛璐璐**（90 年代） | 赛璐璐平涂色块，颗粒胶片质感，手绘速度线，暖黄打光，夸张透视广角 |
| **写实武侠 / 港式** | 自然光质，写实布料与金属反射，手持微晃纪实跟拍，克制特效，重力真实 |
| **国风 3D CG** | 水墨晕染体积雾，玉质柔光，衣袂流体解算，写意留白构图 |

有参考图 → **按四要素格式反推图片画风并锁定**，分析模块与提示词**共用同一句描述，不换措辞**（跨模块零漂移）。无参考图 → 默认锁现代作画流。
