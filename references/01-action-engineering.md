# 01 · 动作工程层

> 这一层决定打斗**对不对**。它没过，后面的节奏、运镜、特效全是空转。
> 核心原则：**动作先发生，镜头再选择。**

---

## 1. 武器-距离-节奏三角

不要只认武器名称，要看它**怎样握持、适合多远、偏轻还是偏重、攻击主要沿什么方向展开**。这四项决定了一套打法的全部。

| 载体 | 有效距离 | 节奏基因 | 主动作族 | 打击感（后果形态） | 禁止写成 |
|---|---|---|---|---|---|
| **刃 / 刀 / 剑** | 一臂 + 刃长，中距 | 快、弧线、一触即收 | 旋斩、连斩、居合斩、回马斩、撩刃、挑刺、拖刀、削斩、格挡反刺、交叉下斩、飞斩气刃 | 切割穿透、**整齐断裂**、刃光青白残轨 | 钝器砸烂、凹陷形变 |
| **钝器 / 重兵** | 中距，需抡摆空间 | 重、慢起快落、惯性大 | 抡砸、横扫、震地重击、下压砸、肩撞 | 凹陷形变、冲击波外扩、目标被击退击飞 | 切割、整齐断裂 |
| **拳脚 / 体术** | 四肢完全伸展，近距 | 密、低幅度起手、爆发在末端 | 崩拳、贯手、掌底轰击、回旋踢、下压踢、膝顶、肘击、擒拿转摔投 | 闷响、身体弯折、被击退 | 长兵器弧线、隔空斩 |
| **枪 / 矛 / 棍** | 最长近战距，靠进退控距 | 直线、点、刺、扫堂 | 突刺、点扫、拦拿扎、横扫堂、托劈 | 洞穿、点状破损、被挑飞 | 贴身连打 |
| **能量 / 法术** | 远程，需蓄力窗口 | 慢蓄→快放，蓄力是节奏来源 | 迸发、灼穿、电弧窜行、冲击波外扩、法阵崩解、粒子束贯穿、聚能过载、光刃斩空 | 灼烧、湮灭、整体崩塌坍缩 | 无蓄力窗口的随手中远程 |
| **机械 / 机甲** | 视兵装，中远程 | 重、有机械行程、推进器位移 | 兵装展开、推进突进、装甲冲撞、导弹齐射、机械臂擒拿（**非缠斗**：钳住即刻甩出） | 金属深陷形变、橙红火花、结构错位 | 柔软身法、轻灵踏空 |
| **巨兽 / 兽形** | 体量即距离 | 重、横扫、用体量碾压 | 獠牙咬合、尾扫、翼压、鬃毛炸刺、扑撞、吐息 | 碾压、掀飞、成片结构垮塌 | 人类拳脚招式 |
| **无武器 / 徒手** | 最近，靠步法进出 | 极快、抢占中线 | 瞬身、闪现、踏空、蹬墙翻越、侧空翻闪避、借力回旋、相位穿插 | 精确打击部位 + 身体弯折 | 凭空能量弹 |

**武器形状决定节奏，但不写标签。** "轻巧 / 沉重 / 快速 / 缓慢"不许直接写进提示词，要通过**移动速度、出手时间、动作幅度、攻击范围、命中结果、镜头反应**表现出来。观众自己会读到重量。

## 2. 专属打法四问（每个角色都问一遍）

专属打法是**一套选择动作的方法**，不是一组反复出现的招牌动作。它决定角色怎样接近、怎样处理对方攻击、怎样抢回主动权。

```
        ┌── ① 握持与重量 ──→ 出手时间 / 动作幅度 / 收招惯性
        │
打法 ───┼── ② 有效距离 ────→ 接近方式 / 脱离方式 / 抢位手法
        │
        ├── ③ 攻击方向 ────→ 主要沿什么展开（弧线 / 直线 / 自上而下 / 旋转 / 穿刺）
        │
        └── ④ 出手后破绽 ──→ 哪里空 / 怎样补 / 对手会从哪反打
```

四项答完，这个角色的**接近、闪避、格挡、反击、重击、被击飞后如何刹停回冲**就全部确定了，十五秒内不得换风格。

**刹停不是动作结束，而是下一次进攻的起点。**
角色被轰飞后怎样刹住、怎样重新冲回，必须符合这套打法：重兵器靠砸地卸力再抡起，轻兵器靠翻滚点地弹起，体术靠踏空二段跳，机甲靠推进器反向喷射。

| 检查 | 通过标准 |
|---|---|
| 一致性 | 十五秒内每个动作都能看出属于同一套武学、同一种武器 |
| 变化性 | 具体动作随距离/方向/对手反应不断变化，不是重复三招 |
| 不增员 | 不临时增加图片里没有的武器、肢体、能力 |
| 用户指定武学 | 先理解它习惯的距离、节奏、攻防方式，再变成眼前动作；**门派名与招式名不写进正文**（除非用户要求标注） |

## 3. 一触即分（AI 视频的第一纪律）

**两具身体绝不纠缠在一起。** 这是 AI 视频 morphing（肢体扭曲糊成一团）的头号元凶。

- 打中、格开、推开之后，**双方立刻拉开到武器或四肢完全展开的距离**，再从新位置发起下一招。
- 不设计：缠斗、擒拿、搂抱、锁技、骑压、互相角力。
- 要表现近身压制 → 用**错身掠过**、**贴着兵器边缘穿过**、**打完就弹开的抢进**代替。

**一触即分不限制连打**：快的一方可以在同一落点把十几连击压进一瞬，快到只剩残影——整串连打算**一次接触**，打完照样立刻脱离。

**分离必须写成看得见的动作**，不许写概念词：

| ✅ 写 | ❌ 禁写 |
|---|---|
| 后跳、侧滑、蹬地弹开、翻滚脱离、踏空翻出、借力弹开 | "一触即离""一击即分""瞬间分开" |

## 4. 接触链：接触生出新动作，不是从清单取下一招

```
  接触（真实出手 → 真实接触 → 看得见的结果）
        │
        ├─ 改变位置      （被打到哪 / 被迫退到哪）
        ├─ 改变方向      （武器路线被带偏 / 身体朝向被拧转）
        ├─ 改变落脚      （被逼到边缘 / 被迫踏空 / 踩上残骸）
        ├─ 改变主动权    （攻守互换 / 谁在追谁）
        └─ 改变距离关系  （中距变近距 / 被迫拉开）
        │
        ▼
  下一动作【从刚改变的状态里长出来】
```

- **普通接触不一定造成伤害**。它可以只是改变武器路线、身体方向、落脚位置、追击关系。只要它让下一动作出现新变化，就算成立。
- **禁止**：接触后回到起手位；下一招从"预先列好的招式清单"里依次取用；两人各打各的、招式互不影响。
- **较早重击**要留下**后续持续存在的身体状态或战场状态**（拖行的沟痕、崩塌的结构、未散的气浪），后面的动作要穿过、避开或借用它。

## 5. 整场运动路线：先铺路，再填镜

不要先把镜头格子建好、再向每一格填一次攻击。先把整段看成**一条穿过场景的高速战斗路线**：

```
   起点 ──── 纵深推进 ──── 转折/升高 ──── 换侧 ──── 终结落点
    ▲          ▲              ▲           ▲          ▲
  开场已在   横穿/深入      利用高低差   绕过结构   离起点最远处
  运动中     追击/拦截      蹬壁/踏空    换攻守     终结就在这
```

- **开场时打斗已经在发生**。不写站定亮相、不摆姿势。第一秒就有人在高速运动：冲刺进画、高空坠落进画、追逐进行到一半、第一击已在半空、一方刚被轰进画面。另一方从不同方向/高度/速度进入，立刻咬合。
- **每一段动作都要改变**双方的位置、方向、高低或攻守关系。不能两人同向跑完整场。
- **攻击被挡住后**，守方马上用自己的打法反击；原攻击者再用自己的武器和步法变招或脱身。
- **移动不是空跑**：每次加速、转向、跨越都同时承担接近、闪避、追击、抢位、借力或制造攻击条件。

## 6. 角色数量锚定（忠于画面）

画面 / 概念里有几个主体，就只写几个。绝不无中生有硬塞角色。

| 画面 | 走法 | 要求 |
|---|---|---|
| **单体** | 力量展示流 | 见下方"反站桩三强制" |
| **双体** | 对抗打斗流 | 双方都要主动进攻、化解、反击；每方至少造成 2 次关键接触 |
| **多体** | 几个写几个 | 同上，不合并、不删减 |

⚠️ 参考图只有一头巨兽，却硬编一个对手进来——既毁孤高气质又引入图外角色，禁止。

**"攻击受体" ≠ "对手"**：单体戏为了让攻击有反馈闭环，可以设**背景级受体**——被压制、被摧毁的落点，是背景板不是第二主角，不与主角势均力敌对打。这不算硬加对手。受体设计见 `04`。

## 7. 反站桩三强制（单体戏专用）

单体最容易写废成"钉在一个点上发光 + 砸旁边的柱子/墙"——一堆同质破坏堆特效，看着满、实际空。

| 强制 | 内容 |
|---|---|
| **① 强制瞬移跳位** | 全程瞬移 / 疾掠 / 腾跃 / 俯冲 / 蹬壁 / 踏空 / 相位穿插，有清晰空间跳变（贴脸 A → 高空 B → 远景 C）。**位置一直在跳**，这是番剧感的核心 |
| **② 强制技能招式化** | 技能要有具体形态、轨迹、因果。不许用笼统的"能量爆发[辉光]"糊弄。要写成"掷出凝聚成型的光矛贯穿""掌下拍出如活蛇追踪疾窜的能量裂痕""分裂三道残影同时连击" |
| **③ 强制作画多样性** | 瞬移 / 踏空 / 腾跃俯冲 / 招式释放 / 精准破坏 / 收招**交替推进**，禁止连续 3 个以上同质"砸周围环境"。破坏是运动与招式的副产品，不是主体 |

**单体推荐节奏轴**（每段换一种招式类型 + 换一个空间位置）：

```
蓄势(集中线内收) → 瞬移切入 → 远程招式 → 追踪技 → 跃升俯冲
                → 瞬身近身连击 → 蓄力大招(背景抽象化) → 收招 pose
```

**招式类型菜单**（取"类型"不是"成品招"，必须结合角色现造）：
投射类 / 追踪类 / 范围类 / 近身类 / 突袭类 / 蓄力大招。

⚠️ 至少让 **1-2 个招式从角色独有部件长出来**（獠牙、面甲、尾、翼、鬃毛、兵装挂点、披风、袖中暗器、机械挂架）。这是"现造"最省力的入口。
