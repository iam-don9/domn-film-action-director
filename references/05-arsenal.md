# 05 · 弹药库（取词用 · 禁止泛词）

> 写提示词时从这里取词。**取的是"类型"和"强度"，不是"成品招"**——招式必须结合当前角色现造（见 §5）。

## 2. 泛词黑名单（一个都不许出现）

| 禁用 | 替换为 |
|---|---|
| 打 / 攻击 / 挥舞 / 移动 / 冲过去 | 上方动词库取 |
| 强烈 / 震撼 / 迅猛 / 炸裂 / 压迫感 / 冲击感十足 / 速度感极强 | 直接写**动作顺序、移动距离、镜头变化、破坏结果** |

| 一触即离 / 一击即分 / 瞬间分开 | 后跳、侧滑、蹬地弹开、翻滚脱离、踏空翻出 |

## 4. 攻防往复 · 招式链模板

**基本回合单元**：攻 → 挡/格 → 反制 → 瞬移/闪避 → 再攻，五拍一循环，每拍 0.2-0.5s。

- **连招串接**：主攻方连续 2-3 招不停顿，受方用一个身法 / 残影整体化解后立即瞬身反打。**绝不各打各的**。
- **密度标准**：每 2 秒内至少完成一个完整攻防回合（≥3 拍）+ 一次瞬移跳位。
- **句式**：多用顿号 / 短逗号串联动词，每个招式后就地挂 1 层作画反馈或特效。

> **范例（6 节点仅 2 秒，含 1 次瞬移）**：
> 灼刃劈下、抬臂硬挡迸火线、瞬身绕后、残影撩腕、空翻卸力、反手连斩

> **反面教材**：单句只写一个动作再配三行环境形容词 → 立刻拖慢，禁止。

## 5. 招式现造（禁止套固定招）

从弹药库取的是**"招式类型"**（投射 / 追踪 / 范围 / 近身 / 突袭 / 蓄力大招）与**"作画手法"**（瞬移 / 残影 / 白闪震镜 / 集中线），**不是"成品招"**。

| 角色 | 同一个"瞬身俯冲"的落点 |
|---|---|
| 机兽 | 獠牙面甲喷能量坠击 |
| 龙 | 吐息先导 + 翼压坠落 |
| 机甲 | 兵装展开 + 推进器坠撞 |
| 剑客 | 居合坠斩，刃光先到，人后到 |

⚠️ **严禁套用任何固定招式模板**，尤其别每条都写"三重残影 / 坍缩核心 / 贯穿云层能量光柱"这老三样。

★ **检查参考图的独有造型部件**（獠牙 / 面甲 / 尾 / 翼 / 鬃毛 / 兵装挂点 / 披风 / 袖中暗器 / 机械挂架），**至少让 1-2 个招式从这些部件长出来**——这是"现造"最省力的入口，也是"这个角色专属"的证据。

## 7. 自检用速查表（写作时贴手边）

```
□ 时间不停 T1：零裸写定格/停格/顿帧/凝滞/子弹时间/时间静止
□ 动作不断 T2：切点落在动作中段、方向 match-cut、收势变起势
□ 空间不回 T3：A→B→C→D 净位移，零"归位/回到原处"
□ 一触即分 T4：每次接触后立刻拉开，分离写成后跳/侧滑/蹬地弹开
□ 反馈闭环 T5：攻击有落点+后果；位移有地面回馈+速度特写；反馈带特效
□ 破坏三档 T6：普通≤单体 / 较重沿飞行线 / 终结全场最大，不越级
□ 武器自洽 T7：刃斩不写锤砸、远程不贴身抡
□ 招式现造 T8：无老三样，1-2 招从角色独有部件长出
□ 零泛词 T9：动词全来自弹药库
□ 安全替换 T10：违禁词扫描清零
□ 慢拍：每个进攻爆发前都有独立可读的蓄力慢拍（≥3 次进攻蓄力型）
□ 回合：3-4（10s）/ 4-5（15s）个回合，每回合五拍齐全
□ 节点：≥35（10s）/ ≥50（15s），严格数法，交付前清除编号
□ 首帧：0-1s 锚定主体当前姿态，1s 后才疯切
□ 收尾：终结重击+终结帧 ≤1s，之后零追加
```
