# 04 · 反馈与破坏层

> 这一层决定打斗**有没有分量**。
> 铁律：**没有反馈的动作 = 没发生。**

---

## 1. R1 动作-反馈闭环（★ 不只攻击，任何动作都要有反馈）

```
  动作动词  ──→  [作画/物理反馈]  ──→  回馈特效
   (招式)        (目标/地面怎样)      (火花/尘爆/碎块/速度线/白闪)
       └──────────── 三段一体，缺一不可 ────────────┘
```

| 规则 | 内容 |
|---|---|
| **攻击必须闭环** | 每个攻击性招式必须打在**明确对象**上，并给出与这一击分量匹配的**具体后果**：攻击 → 命中 → 目标反应。严禁"对着前方 / 墙 / 地面放招，再贴一个笼统的 [崩解 + 火花]"——那是朝空气放烟花 |
| **移动也要反馈** | 高速移动 → 地面回馈 [扬尘 / 裂地 / 水花溅开 / 环形气浪] + **一个速度特写**（腿 / 脚 / 身体局部 + 速度线）卖"快"。踏地、蹬壁、落地、疾掠每一下都留回馈痕 |
| **反馈必带特效** | 任何反馈不许光写"目标断了 / 地面裂了"却不挂特效。**反馈本身就要带火花 / 尘爆 / 碎块 / 速度线 / 白闪 / 单色闪** |
| **有明确落点** | 不是泛化的"前方 / 墙面"，而是具体受体（见 §2） |
| **后果匹配分量且每次不同** | 连斩 → 被斩成数段 / 整齐断裂；掌击 / 撞击 → 被击飞老远撞穿结构；能量束 → 洞穿 / 整体崩塌坍缩 / 连锁殉爆。**别复读"[崩解、火花]"** |

## 2. 受体四维 × 尺度耦合

单体戏为了让攻击有反馈闭环，可以设**背景级受体**——被压制、被摧毁的落点，是背景板不是第二主角，不抢主体戏、不与主角对打。**这不算硬加对手。**

| 维度 | 尺度 | 匹配招式 |
|---|---|---|
| **近战级** | 敌潮、围攻群、地面可斩可砸的活体/单位 | 近战刃 / 拳脚 |
| **结构级** | 要塞门、装甲板、立柱、楼体、桥墩 | 近战刃 / 钝器 / 撞击 |
| **火力点级** | 炮台、哨塔、悬浮发射器 | 远程能量 / 投射类 |
| **空中级** | 空中群、悬浮标靶、高空目标 | 远程能量 / 魔法 / 飞斩气刃 |

**耦合铁律**：受体形态匹配招式打击范围。**别让巨剑够不着无人机**（近战武器不挂空中级）；远程能量不挂近战级贴脸受体。

★ **具体受体形态一律结合参考图世界观现造**，别套固定套路、别每条都复读同一种。

## 3. 破坏三档（不许越级）

| 档 | 规模 | 写法 | 何时用 |
|---|---|---|---|
| **一档 · 普通攻击** | ≤ 一个单体物件，从当前场景现取 | 一根立柱被削断、一台载具被掀翻、一面旗被斩落 | 全程高速段 |
| **二档 · 较早重击** | 沿受击者飞行路线铺开 | 撞穿一排结构、犁出长沟长痕、掀翻一整段地面 | 中段重击 |
| **三档 · 终结重击** | 全场最大，形态从**落点材质**取材 | 砸进地面掀环形土浪 + 砸出深坑；砸穿楼体整栋塌陷；砸进水面炸起冲天水柱 + 环形巨浪 | 最后一镜 |

**"严重"来自破坏范围扩大、连续波及更多现有结构、改变更大的空间状态**——不是把烟尘、火花、闪光堆得更满。

⚠️ 三档不越级：**前一档不抢后一档的规模**。别每条都在小攻击上炸楼。

## 4. 介质取材（场景里有什么，气浪就掀什么）

**不默认沙尘。** 从场景现有介质取材：

| 场景 | 气浪掀动 | 落点破坏 |
|---|---|---|
| 沙地 / 荒漠 | 沙尘墙、沙幕 | 环形沙浪、深坑 |
| 水面 / 雨中 | 水幕、水花拉丝、踩踏水环 | 冲天水柱 + 环形巨浪 |
| 雪地 | 雪雾、雪尘爆 | 雪层掀飞、冰面裂纹 |
| 废墟 / 城寨 | 碎石、砖屑、钢筋火星 | 结构错位坍塌 |
| 林地 / 竹林 | 落叶、断枝、竹屑 | 成排拦腰折断 |
| 室内 / 殿宇 | 木屑、碎瓷、幔帐翻飞 | 隔断崩塌、梁柱断裂 |
| 夜市 / 霓虹街 | 灯牌火花、玻璃碎、纸屑 | 招牌坠落、玻璃雨 |
| 空中 / 云海 | 云气撕开、气流涡旋 | 云层被贯穿出长通道 |

**同一种介质、同一个句式不连着用，在场景不同材质之间轮换。**

## 5. 特效挂载（作画特效层）

★ **每个动作节点必挂 ≥1 层**，五类混用，越满越好。**特效跟着动作出现，不在动作写完以后统一添加。**

| 类 | 内容 |
|---|---|
| **线条特效** | 放射状集中线内收（蓄力）、横向速度线扫过（疾掠/挥砍）、动作拖影线、爆闪冲击线 |
| **冲击强调**（画面不停） | 命中瞬间白闪一两帧、色彩瞬间提亮、命中点径向速度模糊、镜头猛震一颤、单色放射背景瞬闪 |
| **单色调冲击** | 见下方 §6 |
| **气场斗气** | 能量气焰缠身、斗气暴涨掀飞碎石、地面被气压压出环形气浪、蓄力时发丝与布料整体被气场推起、爆气瞬间气柱冲天 |
| **残影分身** | 多重残像拖尾、瞬移留下半透明残影链、动作 smear 抹除帧夸张形变、残影追上本体消散 |
| **能量与粒子** | 像液体 / 火焰般流动的能量、光尘逆光海量浮游、能量碎屑如萤火坠落、刃光青白残轨、能量迸发镜头光晕、雨滴在能量场中被点亮 |

**挂载口诀**：动作动词 → 紧跟 `[作画反馈]` → 再叠一层作画特效。三段式让每个节点"有肉有光有线"。

### 招式特效的一致性
特效的**方向、形状、速度和停留时间**要像这一招自然带出来的结果。**同一角色保持同一种特效规律**，不给每一招临时换一种光效。
→ 删掉特效后，人物动作和战斗因果**仍然必须成立**。

## 6. 单色调冲击 + 线条爆发（番剧最带感的样式化特效）

画面继续动、只是瞬间套一层滤镜，**不违反禁停格**。

| 手法 | 规则 |
|---|---|
| **黑白闪** | 重击 / 决胜 / 情绪爆点瞬间，整屏 0.1-0.2s 去色成高对比黑白后立刻切回彩色。**留给全片最重的那几击** |
| **单色染屏** | 整屏被单一色调瞬间笼罩再褪去。选色贴属性：**红**=杀气·危机·暴怒 / **蓝青**=冷冽杀招·寒属性 / **金橙**=大招充能爆发 / **紫品红**=能量过载·异能觉醒 / **黑白**=决胜瞬间 |
| **集中线** | 蓄力时从四周向中心内收收束，爆发时从中心向外炸开，把视线钉在主体或命中点上 |
| **速度线** | 横向 / 斜向流动线，随动作方向铺，表现高速疾掠、瞬移、连斩 |
| **漫画线条背景** | 爆发 / 大招瞬间背景整个抽象化成纯手绘线条 / 网点 / 单色放射，剥离写实环境、只留动作张力 |
| **描边剪影** | 逆光 / 爆发瞬间角色被粗黑轮廓线描边、成高对比剪影一闪 |

★ **频率放开**：黑白闪 + 单色染屏要"好多次"——每个回合的碰撞爆点、每次技能发动、每次大招 / 兵刃触碰都可以来一下，全片 **8-12 次不嫌多**（10s）或 **十几次**（15s）。

★ **但每次必须极短（≤0.15s）、闪完即回、融在运动里**。这样既满是动漫味、又不会闪瞎眼。
集中线 / 速度线 / 漫画线条背景**可以铺满**蓄力与爆发处。

## 7. 作画/物理反馈库（按材质取用）

| 材质 | 反馈写法 |
|---|---|
| **混凝土 / 石材** | 呈放射崩裂并整块炸飞，碎块如陨石拖尾，扬起灰白尘爆 |
| **金属 / 装甲** | 表面深陷形变，迸出一串橙红火花，金属哀鸣中被击穿 |
| **玻璃** | 放射炸裂，碎片如雨向外飞散、拖出速度残影，每片映出打斗残影 |
| **地面** | 冲击波犁开放射状巨沟，环形气浪掀翻一圈地砖 |
| **木材 / 竹** | 沿纹理整齐断开，木屑爆散，断口拖出纤维丝 |
| **水体** | 炸起冲天水柱与环形巨浪，水珠被气浪拉成丝 |
| **★ 移动 / 高速位移** | 脚下地面炸开一圈扬尘 / 水花、身后拖出速度线残影、掠过处草木碎石被气流卷起、蹬壁处墙面迸裂 |
| **★ 落地 / 踏地** | 双足砸地压出放射裂纹与尘环、积水四溅拉出水丝、气浪把周身发丝布料整体掀起 |
| **受体 · 近战级** | 成排被斩断 / 击飞，交错倒退化作光点消散 |
| **受体 · 结构级** | 被洞穿大洞，结构错位坍塌 |
| **空气 / 能量** | 音爆环扩散，气浪扭曲背景，白闪一两帧盖满全屏后迅速褪去 |
| **布料 / 发丝** | 被气场整体掀起猎猎翻飞，末端拖出残影线 |

⚠️ **内部禁用词面**：`裂开`、`蜘蛛纹`、`龟裂`、`网状裂痕` —— 不得出现在可见输出或负面约束中（易被模型渲染成静态裂纹贴图，反而削弱动势）。改用"崩裂""断开""掀翻""压出深沟"等带方向、带结果的动词。

## 8. 场景连续性

- **只使用输入中已有的环境介质和结构**。不新增图片里没有的物件。
- 普通高速段通过**环境掠过、前景视差、脚下变化、碎物带动、路线跨越**证明速度；两次重击通过**真实破坏**证明力量。
- ⚠️ **两种用途不要混**：不要每一击都爆炸（破坏贬值），也不要高速战斗经过后环境毫无反应（速度没有证据）。
- **较早重击改变后的场景继续存在**：后续高速动作要穿过、避开、借用或进一步改变它。
- **伤势、破坏、地面痕迹在后续镜头继续存在**。
- 尘土、烟雾、云气、水花、碎物、光效、近景遮挡**都不能提前盖住关键动作**——先看清接触和身体结果，再让环境后果铺开。
- 结尾需要的破坏在最后一轮高速逼近与接触同一瞬完成，随后被终结帧概括，**不再单独展示破坏后的环境余波**。

## 9. R5 违禁词安全替换（100% 自动应用，全程扫描）

严禁任何暴力 / 血腥 / 死亡的直接描述，**视觉冲击不减**：

| 禁 | 替换为 |
|---|---|
| 鲜血 / 流血 | 暗红色痕迹 / 能量残留辉光 / 飞溅的暗色液滴 |
| 伤口 / 伤口撕裂 | 破损 / 裂痕 / 印记 |
| 死亡 / 尸体 / 斩杀 | 静止 / 沉睡 / 失去意识 / 精准击倒 |
| 杀戮 / 屠杀 | 制服 / 阻止 / 精准击倒 |
| 暴力 / 殴打 | 冲撞 / 强烈撞击 |
| 恐怖 / 血腥 | 紧张 / 震撼 |
| 断肢 / 肢解 | 结构分离 / 部件脱落 / 崩解为碎块 |

> 终结帧允许"破碎、泼洒、飞散"，但必须**走材质路径**（金属崩解为碎片、石质碎块、能量溃散），不走血肉路径。
