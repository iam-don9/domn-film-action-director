# 02 · 节奏结构层

> 这一层决定打斗**有没有起伏**。
> 第一性原理：**全程快 = 没有快。** 匀速密不透风，大脑会把密度当成新的常态，重音被抹平，再多特效也砸不出打击感。

---

## 1. 两种慢（必须分清 · 最容易翻车处）

| | A 类 · 真放慢时间 | B 类 · 低幅度慢拍 |
|---|---|---|
| 是什么 | 升格 slow-motion，时间轴真的变慢 | 画面照常动，只是**动作幅度极小、发力集中** |
| 读起来 | 慢 | 慢 / 稳 / 蓄势 |
| 对 AI 视频 | ⚠️ 受控可用，但**必须绑流动元素 + ramp in→snap back** | ✅ 完全安全，**必须有**，是节奏感主来源 |
| 出现位置 | 命中顿微升格（多次）+ 名场面大升格（1 次） | 每个回合的慢拍装弹与收势喘息 |
| 范例 | 命中瞬间 ramp 进 ~0.3-0.5s 微升格，再 snap 回全速炸飞 | 沉肩坐马稳稳扣住劈来的重锤；单手接住重锤纹丝不退 |

**节奏感 = 幅度节奏（小幅度 ↔ 大幅度）+ 剪辑节奏（长镜对峙 ↔ 快切连打），不是速度节奏。**

灵笼范例：白月魁"单手稳稳扣住劈来的重锤"= B 类慢拍（小幅度接招），紧接"一脚踹飞数十米"= 大幅度爆发。时间没放慢、画面没停，你却明确感到"一慢一砰"。

### B 类慢拍四型（取词见 `05`）

| 型 | 画面 | 用法 |
|---|---|---|
| **蓄力慢拍** | 气场暴涨+集中线内收、腕上/刃上气纹一圈圈缠绕收束、肌肉绷起、重心下沉压步、刀往后缓拉 | ★ ★ **每个进攻爆发前都要单独垫一个** |
| **接招慢拍** | 沉肩坐马稳稳扣住来招、以刃格住劈斩纹丝不退、掌心贴住拳锋卸力 | 攻守交换处 |
| **对峙慢拍** | 低角对望锁定、呼吸起伏、气焰无声翻涌、尘埃在气场里被点亮悬浮 | 回合之间 |
| **收势慢拍** | 披风头发武器滞后飘动、惯性带身形缓转落定、发梢未歇 | 每个回合的呼吸谷底 |

### ★ 慢拍别只堆开场（最高频翻车）

**每个进攻爆发之前**都要有一个**独立可读的蓄力慢拍**（攻击者自己慢一下），而不是全片就 0-1s 慢一下、后面匀速冲到底。

写法铁律：蓄力慢拍要**独立成一拍、给它视觉留白**，别把它溶进后面的连招 run-on 串里一闪而过——溶进去就读不出"慢一下"，节奏塌回匀速。

> 检查：进攻蓄力型 ≥3 次，不能只写防守接招型。

## 2. 回合单元（动漫魂 · 组织单位）

单个回合骨架：**慢拍 → 爆发 → 重音 → 击飞 → 收势**，画面全程在动、零 A 类停格。

```
 ① 慢拍装弹 ──→ ② 高速攻防肉 ──→ ③ 碰撞爆点 ──→ ④ 击飞 ──→ ⑤ 收势喘息
   ≤0.5s          0.2s 招式链       幅度+特效突变    拖出画/砸地    惯性余韵
   B 类小幅度      幅度骤然放大      ★ 重音在这       spacing 骤拉    B 类
                                    逗号不是句号                    呼吸谷底
                                                          │
                                    对方从这谷底怼脸弹射反入场 ──┘
```

| 拍 | 要点 |
|---|---|
| ① 慢拍装弹 | 分**进攻蓄力型**（攻击者出手前自己慢一下：沉刀 / 收拳 / 气纹缠绕护手 / 重心下沉）与**防守接招型**（沉腕稳稳格住纹丝不退）。画面在动（发丝布料被余力掀起、尘埃悬浮），幅度压到最小 |
| ② 高速攻防肉 | 一串 0.2s 招式链（连斩、连点、瞬移绕后、残影连击），密不透风 |
| ③ 碰撞爆点 | 回合高潮。spacing 骤然拉大 + 单色闪 + 线条炸开 + 冲击形变 + 白闪一两帧 + 镜头猛震 + 径向速度模糊 + 作画反馈。**重音靠"突变"砸出，是逗号不是句号** |
| ④ 击飞 | 见"击飞两流派" |
| ⑤ 收势喘息 | 出招方披风头发武器滞后飘动、惯性带身形缓转落定。**这是节奏休止符，不是 A 类停格**。末个回合例外：不留收势，直接终结 |

**回合时长**：每 2-3 秒一个回合。攻守交换用**怼脸弹射**从收势谷底反入场（对方瞬间怼到镜头最前方），不用中景平移。

## 3. 命中一拍四段（打击感的核心）

每个关键碰撞点必须齐备，画面全程有流动元素、绝不裸停。

```
⓪ 装弹：半拍 B 类蓄力慢拍（独立成拍）── 落差 > 速度，丢了"砰"不成立
   ↓
① 接触·砸入：镜头猛震一颤 + 命中点径向速度模糊 + 白闪一两帧（画面继续走）
   ↓
② 顿一下·命中顿微升格：ramp 进 ~0.3-0.5s，被击者沿受力方向压缩形变（smear），
   ★ 碎屑/火花/水花/断口仍在缓慢流动外扩（非冻结）。可多次
   ↓
③ 击飞·snap 回速：snap back 全速，spacing 骤然拉大，被击者被打飞 / 拖出画面撞结构
   ↓
④ 目标反馈 + 回馈特效：作画反馈 [按材质] + 单色闪/线条炸开/碎屑迸飞
   ★ 反馈本身必带回馈特效，不许光写"目标断了"却不给火花/尘爆/碎块
```

**字面冻结词全禁**：定格、顿帧、时间静止、子弹时间、hit-stop、凝滞、静滞、悬停。
微升格 ≠ 冻结：微升格是**绑流动元素的受控减速**，两回事。

### 击飞两流派（选一条，都要先有半拍慢拍）

| 流派 | 写法 | 适用 |
|---|---|---|
| **力学真实流**（默认推荐） | 克制慢镜，被击者**快速拖出画面 / 结实砸地撞穿结构**，spacing 骤拉，身形大幅度炸开，配白闪震镜。"还没反应就被打出去" | 写实武侠、机甲、巨兽 |
| **炫技慢镜流** | 命中后叠命中顿微升格（或名场面大升格），被击者头发衣摆飘动着漂移飞出，配能量拖尾 | 番剧、能量系、名场面 |

## 4. 重击三档

| 档 | 出现 | 破坏规模 | 慢镜 | 作用 |
|---|---|---|---|---|
| **普通攻击** | 全程 | ≤ 一个单体物件（从场景现取） | 无 | 推进攻防、改变位置/主动权 |
| **较早重击** | 中段（约 40-55% 处） | 沿受击者飞行路线铺开：撞穿一排结构、犁出长沟长痕 | **不进慢镜**（慢镜蓄力名额留终结） | 改变战局，留下持续状态 |
| **终结重击** | 最后一镜 | 全场最大，形态从落点材质取材 | ★ 全片唯一/最完整的一次慢镜蓄力 | 直接结束视频 |

### 较早重击（高速中直接爆发）

- 优先用**一个完整时间段**写完，不能断在拳头/武器刚打中的位置。
- **不进慢镜**——在高速交锋中直接爆发：上一动作刚抢出破绽，下一瞬攻击已砸向目标，越突然越有分量。
- 出手前用半句写清攻击方向与准确落点，**节奏不放慢**；写的落点必须就是真正被打中的地方（若途中被挡，改写被挡的位置）。
- 打中的一瞬画面不停在接触点：短震、明暗闪、碎片迎面掠过——**但身体结果必须同时爆发**。
- 受击者沿攻击方向猛烈离开接触点，**最好直接飞出画面**；无法飞出也要迅速离开接触位置，画面中央只剩沿同一方向延伸的气旋、武器轨迹残光、压力轨迹、碎片或场景介质。
- 一飞出画，镜头**立刻超快后拉 / 快速追远 / 转超远景**，用后拉速度本身表现力量，重新找到仍在飞行的受击者，**不在空画面上停留**。
- 受击者按自己的武器和移动方式**强行刹停**，沿原飞行方向拖出一条清楚连续的长痕；**刚停住就立刻借力重新冲回**——上一秒沟痕还在，下一秒已沿新攻击路线穿过画面。
- ⚠️ 这一整段属于同一次重击：不在中间重新起手，不把飞行和破坏写成另一件事。

### 终结重击（最后一镜，从慢镜蓄力到破坏全景**同一镜内完成**）

```
 高速进入 ──→ 进入慢镜头蓄力（0.5-0.7s）──→ 接触瞬间恢复高速
                    ↓                              ↓
          看清攻击动作/完整路线/准确落点     决定性结果 + 材质飞散同时爆开
                                                    ↓
                                        高饱和单色终结帧（0.2-0.4s）──→ 结束
```

1. **从当前位置与破绽重新设计终结路线**，不是把较早重击的落点打得更重，而是**打开一条新的攻击路线**。
2. 慢镜蓄力只展示**命中前的蓄力过程**，不展示受击后结果。用 1-2 句大白话看清攻击者怎样把身体 / 武器 / 下落 / 旋转 / 冲刺收进最后一段攻击轨迹。**不让角色站在原地等待**，不解释抽象的内部力量传递。
3. 蓄力完成的最后一刻慢镜**立即结束**；真正接触恢复高速，身体反馈、材质破坏、冲击扩张、场景结果在速度恢复的一瞬爆开——**形成明确的快慢反差**。
4. 命中后**不再切镜**：摄影机俯冲 / 急坠 / 超快追随，跟着受击者一路砸向落点；砸进落点的一瞬爆发全场最大的一次破坏。
5. 最后一击打中后，对方**整个身体必须马上出现清楚变化**；只有局部受损不算终结。
6. 镜头停在飞散介质还没落定的破坏全景上，**保持约 0.2-0.4s 后直接结束**，不补起身、收招、对话、远景收尾。

**自检**：若蓄力只是"举起武器等待"，或接触结果只是"碰到、凹一下、画面震动"→ 回到前面的高速动作，重新设计机会、轨迹与伤害。漫长蓄力配轻微伤害 = 假高潮。

## 5. 终结帧协议

统一写法：

**命中 → 环境被主色压掉 → 人物细节保留 → 结果沿攻击方向铺开 → 短暂保持 → 结束**

| 要素 | 规则 |
|---|---|
| **主色** | 高饱和红 / 深黑 / 强白 / 金橙 / 紫品红 —— 从角色识别色、技能色、环境光、火光、能量、受击材质中提炼。**红不只属于鲜血**（机械红光、警示色、能量同样可以） |
| **抽掉什么** | 真实环境、次要颜色 |
| **保留什么** | 双方人物的脸、服装、装甲、武器、体积、原有明暗。**人物不变成无细节剪影** |
| **铺开什么** | 受击者的破碎 / 泼洒 / 碎片 / 材质飞散，沿攻击方向占据画面大面积 |
| **攻击者姿态** | 停在**刚完成这一击的姿态**（属于这一击，不是事后重新摆的胜利动作） |
| **时长** | 0.2-0.4s，随即结束 |
| **之后** | ❌ 不再追加：胜者回头、另行收招、落地、对手继续翻滚、环境余震、远景说明 |

**变体（想避免每条都单色染屏时二选一）**：
- ① 属性色爆闪收尾（红 / 金 / 黑白，贴大招属性）
- ② 动量出画——末招甩出画外、速度线漫过镜头瞬间收黑

## 6. 时长配比表（按总时长伸缩）

| 总时长 | 开场锚定 | 主体博弈 | 巅峰 | 收尾 | 回合数 | 镜头数（默认档） | 节点下限 |
|---|---|---|---|---|---|---|---|
| **5s** | 0-0.8s | 0.8-3s | 3-4.2s | 4.2-5s | 2 | 4-6 | 18 |
| **10s** | 0-1s | 1-6s | 6-8s | 8-10s（≤1s） | 3-4 | 8-12 | 35 |
| **15s** | 0-1s | 1-9s | 9-13s | 13-15s（≤1s） | 4-5 | 10-14 | 50 |

**收尾铁则**：终结重击 + 终结帧占最后 ≤1 秒（5s 档 ≤0.8s）。忌：镜头缓慢拉远 / 环绕收尾、升格慢收、收尾拖到 2-3 秒、打完画面停住再结束。

**首帧锚定**：给了参考图 → 参考图就是第 1 帧。0-1s 从图中主体的当前姿态、当前景别直接启动，第一个动作发生在主体身上（眼神骤变 / 拔刀 / 瞬身蓄力 / 迎击）。**严禁开头加图里没有的环境空镜或运镜**。0-1s 不疯切，先让主体动起来。

## 7. 节点密度（防"看着满、实际空"）

**有效动作**：一次攻 / 挡 / 闪 / 瞬移跳位 / 反制 / 蓄力 / 技能 / 破坏 / 能量释放各算一个。

**严格数法（砍三种水分）**：
1. 环境反应 / 作画反馈不算（那是 `[]` 里的特效，不是动作）
2. 同一类动作换词重复只算 1 个（俯冲→撕空→急转→再俯冲 = 1 种飞行位移）
3. 纯状态（发光 / 蓄能 / 悬停）不算

**凑够密度靠"有区别、推进性的招式"**——每 1.5-2 秒换一个不同的招（斩 / 突刺 / 掌击 / 踢技 / 能量弹 / 瞬身撞 / 缠绞…），不是同一个动作反复飞 / 反复砸。瞬移只是招式之间的连接。

**加密手法**：
① 连招拆分（"连斩三刀"拆成 3 个节点）
② 攻防急速往复（攻→挡→反→闪 一秒内塞完）
③ 加过渡微动作（拧腰 / 点角 / 踏空 / 借力）
④ 疯切本身制造节点（硬切跳位到新方位打新招 = 新节点）
⑤ 单体拆细破坏对象、能量层次、瞬移调度

> ⚠️ **生成时可编号 ①②③ 自查数量，但交付正文必须清除全部编号**，只保留 `[时间戳]` 与 `[作画反馈]`，是一段纯净连续文本。

**单一动作不得占用超过 1.2 秒。**

### ⚠️ 最易踩的坑：快 ≠ 减字减特效

加密动作时**严禁靠删描写来提速**。每个动作节点都必须就地紧跟 `[作画反馈]` 或特效层描写——**动作越密、特效越满、字数越多，三者同向增长**。要砍的只有"开场之外的静态环境铺陈"（氛围铺陈仅限 0-1s）。成品字数偏少 = 特效没写够，去补。
