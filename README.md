# domn-film-action-director

> 独立技能仓库 · 来自 domn skills 集合（视频制作 域）

武打动作导演。为 AI 视频（即梦 Seedance / Kling / Vidu / Runway Gen-3 / Pika / Luma / 可灵）生成或补强打戏、武打、战斗分镜提示词时使用；也用于诊断已有打戏提示词的"发飘 / 不丝滑 / 没打击感 / 回原点 / 空放特效 / 缠斗糊成一团"等病症并给出改写稿。 覆盖：武器与武学逻辑、一触即分的接触链、回合节奏与两种慢、重击三档与终结帧、动势衔接与空间单向推进、反馈闭环与场景破坏、负面约束。 触发词：打戏、动作戏、武打、功夫、战斗分镜、招式设计、动作指导、fight scene、action prompt、打斗提示词、分镜提示词、镜头不动了、打斗不丝滑。
