# domn-film-action-director

![domn-film-action-director 封面](assets/readme/hero.webp)

> 为 AI 视频（即梦 Seedance / Kling / Vidu / Runway / Pika / Luma / 可灵 等）生成或补强**打戏、武打、战斗分镜提示词**，并诊断已有提示词「发飘 / 不丝滑 / 没打击感 / 回原点 / 空放特效 / 缠斗糊成一团」等病症，给出改写稿。

## 是什么

你是直接给动画师 / 视频模型**讲戏的动作导演**。产出的不是一段好看的描写，而是一条**能被摄像机拍出来、能被视频模型执行出来、每一帧都有明确因果的连续动作**。

覆盖：武器与武学逻辑、一触即分的接触链、回合节奏与两种慢、重击三档与终结帧、动势衔接与空间单向推进、反馈闭环与场景破坏、负面约束。

## 怎么做（工作流）

<p align="center">
  <img src="./assets/readme/workflow.svg" width="100%"
       alt="domn-film-action-director 五步工作流：S1 看清角色与场景 → S2 定打法 → S3 铺整场路线 → S4 排回合重击 → S5 成稿。唯一裁判：动作正确 ＞ 结构成立 ＞ 呈现好看。">
</p>

1. **S1 看清**：锁定人物外形 / 服装 / 武器 / 体型，以及战场 / 天气 / 建筑 / 介质；人物进场景后不保留棚拍背景。
2. **S2 定打法**：为每个角色设计一套**专属打法**（选择动作的方法，而非一组招牌动作）。
3. **S3 铺路线**：先把整段看成一条穿过场景的高速战斗路线——从哪打到哪、经过哪、在哪终结。
4. **S4 排节奏**：回合单元 + 两次重击 + 终结帧。
5. **S5 成稿**：**动作与切镜先完成，秒数最后填**；只写摄像机能拍到的。

### 三层架构（内化用）

| 层 | 管什么 | 塌了的症状 |
|---|---|---|
| **动作层** | 谁在打、用什么打、打中哪、人去了哪 | 特效满屏但动作空、招式同质、两人糊成一团 |
| **结构层** | 回合、慢拍↔爆发落差、重击三档、终结帧 | 全程匀速没起伏、结尾拖沓、重击不炸 |
| **呈现层** | 运镜、特效、节奏密度、画风 | 发飘接不上、打回原点、镜头太碎看不清 |

> 唯一裁判：**动作层正确 > 结构层成立 > 呈现层好看**。任何呈现层手段都不能救一条「动作本身接不上」的戏。

## 怎么用

将本仓库内容放入支持 `SKILL.md` 的 Agent 技能目录：

- **WorkBuddy**：`~/.workbuddy/skills/domn-film-action-director/`
- **Codex / 其他**：对应 skills 目录

然后在对话中触发，例如：

```
用 domn-film-action-director 给我写一段 30 秒的巷战打戏分镜提示词，
主角用长刀，要求重击三档 + 终结帧。
```
